🧠 How the AI Reached This Result

The prototype processes the retinal image through multiple stages before producing the prediction.
👁️

1. Retinal Image

The uploaded fundus photograph is used as the input to the screening system.

⚙️

2. Preprocessing

The image is resized to 224 × 224 pixels and prepared for CNN processing.

🧠

3. CNN Classification

The CNN extracts visual features and produces probabilities for five classes.

🎯

4. Prediction

The class with the highest model probability is selected as the predicted category.

🔥

5. Grad-CAM

Grad-CAM identifies image regions that contributed strongly to the selected prediction.

💡

6. Human Interpretation

The heatmap helps researchers understand where the model focused during prediction.

⚠️ The heatmap explains model behavior. It should not be interpreted as a medical diagnosis.
